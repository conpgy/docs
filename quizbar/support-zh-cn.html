背题宝技术支持

更新日期：2026年10月21日
简体中文 · English

背题宝是一款 macOS 题库悬浮轮播工具：把 Excel 题库做成一张置顶悬浮卡片，逐题循环播放；开启"选中取题"后，在任意应用里划选题目文字，卡片立即显示该题的答案与解析排版。所有数据均在本地处理，不会上传至任何服务器。

功能一览

功能说明
悬浮轮播卡片置顶于所有应用之上，按设定间隔逐题循环播放，可暂停、上一条、下一条。
智能排版自动识别单选、多选、判断、简答题型：选项分行展示，正确答案打 ✓ 并高亮。
选中取题开启后在任意应用中划选题目文字，松开鼠标即识别并跳转到对应题目。
防拍模式开启后卡片在录屏、截图、共享屏幕中自动隐形，本机观看不受影响。
多工作表自动合并 Excel 中所有工作表的内容一起轮播。
自动重载修改并保存 Excel 后无需重启，卡片内容自动更新。
背景自适应根据卡片背后屏幕内容的明暗，自动切换深色/浅色外观。
位置记忆默认出现在屏幕右上角；拖动到任意位置后自动记忆，重启保持。

快速上手

  1. 打开背题宝，把 .xlsx 题库文件拖到卡片上（或右键 → 打开 Excel 文件）；
  2. 卡片开始逐题轮播：单击卡片 暂停/继续，按住拖动 移动位置，右键 打开全部设置；
  3. 点击右上角 🎯 图标开启"选中取题"，👁 图标切换"防拍"。
题库模板建议：第一列为题目，随后依次为正确答案（如 B、ABD、对/错）与各选项内容。空列会被自动跳过。

常见问题

1. 支持哪些文件格式？

支持 .xlsx 格式的 Excel 工作簿。包含多个工作表时，所有工作表的内容会按顺序合并轮播，底部信息栏会显示当前题目所属的工作表名称。

2. 题目是如何被识别成不同题型的？

应用会扫描每一行的单元格，按以下规则自动判断题型：

  • 某个单元格内容为单个字母 A~F → 判定为选择题答案，其后单元格为选项；多个字母（如 ABD）则按多选题处理；
  • 单元格内容为 对 / 错 / 正确 / 错误 / √ / × 等 → 判定为判断题；
  • 末列为较长文本且无选项 → 判定为简答题，答案以文字形式高亮展示；
  • 题目与答案之间的"难度""分类"等列会自动归入底部信息栏。

无法识别的行会以单行文本样式轮播，不影响其他题目。

3. 选中取题没有反应，怎么办？

请按顺序排查：

  1. macOS：需要"屏幕录制"权限。请到 系统设置 → 隐私与安全性 → 屏幕录制，打开背题宝的开关，然后完全退出并重新打开应用（权限对重启后的进程生效）；
  2. 确认卡片底部状态栏显示"选中取题"而非"取题不可用/无录屏权限"；
  3. 划选时请确保鼠标有明显的拖动位移（轻点一下不会触发）；
  4. 选中的文字必须在屏幕上完整可见（被遮挡的部分无法识别）；
  5. 识别到的文字会与题库题干做模糊匹配（相似度 ≥ 72% 即命中）。若屏幕上的题目不在当前加载的题库中，将无法切换。

4. 为什么显示"无录屏权限"或"取题不可用"？

"无录屏权限"表示系统未授予屏幕录制授权（选中取题依赖它），请参照上一条完成授权并重启应用。"取题不可用"表示截图采集连续失败，通常是权限刚被修改尚未重启应用，或显示器刚发生变化，稍候或重启应用即可恢复。

5. 防拍模式是什么原理？会被发现吗？

防拍模式使用 macOS 系统级窗口保护能力（窗口共享开关）：开启后，录屏软件、截图工具、会议共享屏幕中都不会出现这张卡片，但您本机屏幕上照常显示。这是操作系统提供的正规能力，并非规避检测的漏洞。

防拍只能屏蔽软件采集，无法防止手机等外部设备直接拍摄屏幕。

6. 悬浮卡片的位置可以固定吗？

可以。默认出现在屏幕右上角；按住卡片拖动到任意位置后，应用会记住新的右上角锚点，切题、重启都不会跑位。右键菜单提供"复位到屏幕右上角"可随时恢复默认。卡片任何情况下都不会超出屏幕边界。

7. 修改了 Excel 内容会自动更新吗？

会。应用每个轮播周期都会检测文件修改时间，保存后内容自动重新加载，无需重启。

8. 如何反馈问题？

发送反馈时，建议提供以下信息：

  • 背题宝版本号；
  • macOS 版本；
  • 问题发生的具体操作步骤；
  • macOS 用户可附上日志文件 /tmp/quizbar_pick.log（如涉及取题问题）。
